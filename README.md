# MLOps-проект для магистерской диссертации

**Тема:** Сравнительный анализ методов регрессии в рамках MLOps-пайплайна.

Этот репозиторий содержит код, эксперименты и описание архитектуры для моей магистерской диссертации. Проект демонстрирует полный жизненный цикл ML-моделей: от анализа данных до развертывания в контейнеризованной среде.

---

## 📁 Структура репозитория

На данный момент проект содержит следующие ключевые файлы и папки:

*   **`california_ml_methods.ipynb`** — Jupyter-ноутбук с экспериментами на датасете **California Housing**. Содержит реализацию и сравнение всех запланированных моделей (линейная, полиномиальная, деревья решений, случайный лес, XGBoost, CatBoost, LightGBM).
*   **`medical_ml_methods.ipynb`** — Jupyter-ноутбук с полным циклом экспериментов на датасете **Medical Cost Personal Insurance**. Включает обучение и сравнение всех запланированных моделей (линейная, полиномиальная, деревья решений, случайный лес, XGBoost, CatBoost, LightGBM).
*   **`insurance.csv`** — исходный набор данных для экспериментов с медицинскими страховками.
*   **`catboost_info/`** — служебная папка, создаваемая библиотекой CatBoost в процессе обучения.

В дальнейшем структура будет дополнена папками `src/` (исходный код), `models/` (сохраненные модели), `deployments/` (конфигурации Docker и Kubernetes) и `tests/` (модульные тесты).

---

## 🎯 Цель и задачи проекта

**Цель:** Разработать и сравнить эффективность различных моделей машинного обучения для решения задач регрессии, а также создать автоматизированный пайплайн для их эксплуатации.

**Задачи:**
1.  Провести исследовательский анализ данных (EDA) для двух датасетов.
2.  Реализовать и обучить моделей машинного обучения и глубокого обучения. Пока реализованы только методы машинного обучения: линейная, полиномиальная, дерево решений, случайный лес, XGBoost, CatBoost, LightGBM. Может быть больше.
3.  Провести сравнительный анализ моделей по метрикам качества (RMSE, MAE, R²) и времени обучения/инференса.
4.  Разработать микросервис на FastAPI для инференса моделей.
5.  Контейнеризовать приложение с помощью Docker.
6.  Настроить CI/CD пайплайн (GitHub Actions) и развертывание в Kubernetes.
7.  Внедрить систему мониторинга (Prometheus + Grafana) и трекинга экспериментов (MLflow).

## 📊 Описание датасетов

В проекте используются два датасета для оценки моделей на разных типах данных.

### 1. California Housing
*   **Описание:** Классический набор данных по ценам на жилье в Калифорнии (1990 год). Все признаки числовые.
*   **Размер:** 20 640 записей, 8 признаков.
*   **Целевая переменная:** `MedHouseVal` — медианная стоимость дома (в $100,000).
*   **Роль в проекте:** Используется как **эталонный бенчмарк** для «чистого» сравнения алгоритмов без влияния категориальных переменных.

### 2. Medical Cost Personal Insurance
*   **Описание:** Датасет для прогнозирования индивидуальных медицинских расходов. Содержит смешанные типы признаков (числовые и категориальные).
*   **Размер:** 1 338 записей, 6 признаков.
*   **Целевая переменная:** `charges` — стоимость медицинской страховки.
*   **Роль в проекте:** Используется для проверки эффективности пайплайнов на реальных данных с категориальными признаками.

## 🔬 Эксперименты и первые результаты

На данный момент выполнены следующие этапы:

1.  **Проведен EDA** для обоих датасетов (распределение признаков, корреляционный анализ, обработка пропусков).
2.  **Реализовано обучение 8 моделей** на датасете Medical Cost Personal Insurance. Результаты (R² Score) позволяют предварительно оценить лидеров:
    *   **CatBoost** показал наилучшее качество, особенно при работе с категориальными признаками.
    *   **XGBoost** и **LightGBM** продемонстрировали близкие результаты, уступая CatBoost на текущих данных.
    *   Классические методы (линейная регрессия) ожидаемо показали более низкую точность из-за нелинейности данных.
3.  **Запущено первичное сравнение** на датасете California Housing для верификации результатов на независимых данных.

Более детальные результаты и графики представлены в соответствующих Jupyter-ноутбуках.

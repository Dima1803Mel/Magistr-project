# MLOps-проект для магистерской диссертации

**Тема:** Сравнительный анализ методов машинного и глубокого обучения в рамках MLOps-пайплайна.

Этот репозиторий содержит код, эксперименты и описание архитектуры для моей магистерской диссертации. Проект демонстрирует полный жизненный цикл ML-моделей: от анализа данных и обучения моделей до развертывания в контейнеризованной среде с мониторингом.

---

## 📁 Структура репозитория

На данный момент проект содержит следующие ключевые файлы и папки:

- **`notebooks/california_ml_methods.ipynb`** — Jupyter-ноутбук с экспериментами на датасете **California Housing**. Содержит реализацию, сравнение и оптимизацию (Random Search для XGBoost) всех запланированных моделей машинного обучения.
- **`notebooks/medical_ml_methods.ipynb`** — Jupyter-ноутбук с полным циклом экспериментов на датасете **Medical Cost Personal Insurance**. Включает обучение и сравнение всех моделей ML, а также анализ важности признаков.
- **`insurance.csv`** — исходный набор данных для экспериментов с медицинскими страховками.
- **`catboost_info/`** — служебная папка, создаваемая библиотекой CatBoost в процессе обучения.

**В планах на октябрь–декабрь 2026:**
- `src/` — исходный код (модели, пайплайны, утилиты).
- `api/` — микросервис на FastAPI для инференса моделей.
- `ui/` — веб-интерфейс на Streamlit.
- `deployments/` — конфигурации Docker и Kubernetes.
- `tests/` — модульные тесты (pytest).
- `results/` — таблицы и графики для диссертации.

## 🎯 Цель и задачи проекта

**Цель:** Разработать и сравнить эффективность различных моделей машинного и глубокого обучения для задач регрессии, а также создать автоматизированный MLOps-пайплайн для их эксплуатации.

**Задачи:**

1. ✅ Провести исследовательский анализ данных (EDA) для двух датасетов.
2. ✅ Реализовать и обучить методы машинного обучения: линейная регрессия, полиномиальная регрессия, дерево решений, случайный лес, метод опорных векторов (SVM), k-ближайших соседей (k-NN), XGBoost, CatBoost, LightGBM.
3. 🔄 Реализовать методы глубокого обучения: MLP (FastAI), RNN/LSTM (PyTorch).
4. 🔄 Провести оптимизацию гиперпараметров (Random Search для XGBoost — выполнено; Grid Search для других моделей — в планах).
5. ⏳ Провести сравнительный анализ моделей по метрикам качества (RMSE, MAE, R²) и времени обучения/инференса.
6. ⏳ Разработать микросервис на FastAPI для инференса моделей.
7. ⏳ Разработать веб-интерфейс на Streamlit для визуализации предсказаний.
8. ⏳ Контейнеризовать приложение с помощью Docker.
9. ⏳ Настроить CI/CD пайплайн (GitHub Actions) и развертывание в Kubernetes.
10. ⏳ Внедрить систему мониторинга (Prometheus + Grafana) и трекинга экспериментов (MLflow + PostgreSQL).

*Легенда: ✅ — выполнено, 🔄 — в процессе, ⏳ — запланировано.*

## 📊 Описание датасетов

В проекте используются два датасета для оценки моделей на разных типах данных.

### 1. California Housing

- **Описание:** Классический набор данных по ценам на жилье в Калифорнии (1990 год). Все признаки числовые.
- **Размер:** 20 640 записей, 8 признаков.
- **Целевая переменная:** `MedHouseVal` — медианная стоимость дома (в $100,000).
- **Роль в проекте:** Используется как **эталонный бенчмарк** для «чистого» сравнения алгоритмов без влияния категориальных переменных.

### 2. Medical Cost Personal Insurance

- **Описание:** Датасет для прогнозирования индивидуальных медицинских расходов. Содержит смешанные типы признаков (числовые и категориальные).
- **Размер:** 1 338 записей, 6 признаков.
- **Целевая переменная:** `charges` — стоимость медицинской страховки.
- **Роль в проекте:** Используется для проверки эффективности пайплайнов на реальных данных с категориальными признаками. Позволяет наглядно продемонстрировать преимущество CatBoost при работе с категориями без предварительного кодирования.

## 🔬 Эксперименты и текущие результаты

На данный момент выполнены следующие этапы:

1. **Проведён EDA** для обоих датасетов: распределение признаков, корреляционный анализ, обработка пропусков и выбросов, визуализация зависимостей.
2. **Реализовано обучение 9 моделей ML** на двух датасетах:
   - Линейная регрессия
   - Полиномиальная регрессия (степень 2)
   - Дерево решений
   - Случайный лес
   - Метод опорных векторов (SVM)
   - k-ближайших соседей (k-NN)
   - XGBoost
   - CatBoost
   - LightGBM
3. **Проведена оптимизация гиперпараметров** для XGBoost с помощью Random Search. Результаты залогированы.
4. **Предварительные выводы:**
   - **CatBoost** показал наилучшее качество (R²) на датасете Medical Cost, особенно при работе с категориальными признаками.
   - **XGBoost** и **LightGBM** продемонстрировали близкие результаты, уступая CatBoost на текущих данных.
   - Классические методы (линейная регрессия) ожидаемо показали более низкую точность из-за нелинейности данных.
   - **SVM** и **k-NN** показали результаты хуже бустингов, что согласуется с теоретическими ожиданиями для табличных данных.

Более детальные результаты и графики представлены в соответствующих Jupyter-ноутбуках.
